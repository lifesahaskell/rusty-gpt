## Failure Signature

## Impact

Describe who or what is blocked: default branch, release, deployment, security workflow, multiple PRs, one PR, or optional checks.

## Likely Cause

State the most likely root cause and confidence level. Separate evidence from inference.

## Recommended Next Step

Write one backlog-ready action item with acceptance criteria and a validation command.

## Open Questions

List only questions that materially affect ownership, priority, or fix strategy.
